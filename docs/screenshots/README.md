# Актуальні скріншоти

Ці зображення знято з реального DEMO-стека MeetBroker, а не з ранніх
дизайн-концептів. Вони використовуються в README, актуальній дизайн-системі
та технічному DOCX.

Щоб відтворити набір після зміни інтерфейсу:

```bash
docker compose up -d --build
node scripts/capture-doc-screenshots.mjs
```

Скрипт входить під демонстраційним адміністратором, не змінює дані,
створює п'ять оптимізованих WebP-знімків для desktop і mobile та готує
PNG-версію brand mark для DOCX.

Зображення підпадають під загальну
[CC0-ліцензію асетів](../../LICENSES/CC0-1.0.txt).
