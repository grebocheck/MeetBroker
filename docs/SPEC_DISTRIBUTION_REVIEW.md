# Перевірка права на поширення конкурсного PDF

Дата перевірки: **31 липня 2026 року**

## Що перевірено

1. Оригінальний `spec-uk.pdf`.
2. Публічну [сторінку турнірів UA-Skills](https://ua-skills.com/tournaments),
   де конкурс «Бронювання переговорних» і кнопка отримання завдання доступні
   відвідувачам.
3. [Умови використання UA-Skills](https://ua-skills.com/terms-of-use),
   оновлені 21 квітня 2026 року.
4. [Політику конфіденційності](https://ua-skills.com/privacy-policy).

## Висновок

Публічний доступ до завдання не є автоматичною ліцензією на повторне
розміщення PDF у сторонньому open-source репозиторії.

Розділ 6 умов UA-Skills говорить, що авторські права на створений учасником
код або контент залишаються за учасником. Він не надає учаснику ліцензію на
технічні завдання, фірмове оформлення чи інші матеріали організатора. Сам PDF
також не містить license/redistribution grant.

Отже, за доступними офіційними матеріалами **право повторно поширювати
`spec-uk.pdf` не підтверджено**. Це не юридичний висновок, а консервативна
перевірка опублікованих умов.

## Прийняте рішення

- PDF прибрано з поточного Git tree та додано до `.gitignore`;
- README веде на офіційну сторінку UA-Skills;
- локальну копію можна зберігати для особистої конкурсної роботи, але вона не
  входить до MIT/CC0-дистрибутива MeetBroker;
- acceptance-матриця переказує функціональні вимоги своїми словами, не
  відтворюючи оформлення чи повний текст PDF.

## Важлива межа

PDF був присутній у попередньому публічному коміті, тому його blob лишається
доступним у Git history. Повне вилучення вимагало б переписування історії та
force-push, що конфліктує з конкурсною вимогою зберегти прозору історію
розробки. Таку операцію свідомо не виконано.

Якщо UA-Skills письмово підтвердить, що PDF можна передруковувати, його можна
повернути з чітким copyright notice. Якщо правовласник попросить повного
видалення, історію слід очистити окремою контрольованою процедурою та
повідомити організатора про зміну commit SHA.
