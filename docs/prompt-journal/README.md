# Журнал промптів

Журнал фіксує використання AI під час створення MeetBroker. Його мета —
відтворити походження рішень і змін, а не зберігати приховані міркування або
кожну службову відповідь інструментів.

## Що записуємо

- дату й послідовний номер взаємодії;
- запит користувача дослівно або без втрати змісту;
- короткий підсумок результату;
- прийняті продуктові чи технічні рішення;
- файли й коміти, що з'явилися внаслідок взаємодії.

## Що не записуємо

- паролі, токени, cookie та значення секретних env;
- персональні дані, не потрібні для розробки;
- повний вивід команд і залежностей;
- внутрішні приховані міркування моделі;
- випадкові обговорення, що не вплинули на продукт або код.

## Формат

Один файл охоплює один день або одну завершену тему:

```text
YYYY-MM-DD-short-topic.md
```

Записи не переписуються заднім числом для зміни історії. Уточнення додаються
новим пунктом із посиланням на попереднє рішення. Після створення коміту його
короткий hash додається до відповідного запису наступною документальною
зміною, якщо він ще не був відомий у момент написання.
